# Advanced Foundry

A collection of Solidity smart contract projects built with Foundry.

## Projects

### 1. 🪙 ERC20 Token (`foundry_erc20`)

Standard ERC20 token implementation with OpenZeppelin contracts and manual implementation.

-   Token minting and distribution
-   Transfer and approval mechanisms
-   Comprehensive test suite

---

### 2. 🎨 NFT with IPFS (`foundry_nft`)

ERC721 NFT implementation with IPFS integration for decentralized storage.

-   ERC721 standard implementation
-   IPFS storage integration
-   Metadata management via JSON
-   Pinata pinning for persistence
-   MetaMask wallet integration

---

### 3. 💎 DSC - Decentralized Stable Coin (`Defi_DSC`)

Algorithmic stablecoin protocol with crypto-collateralization and Chainlink oracles.

-   Pegged 1:1 to USD
-   Crypto-collateralized (wETH & wBTC)
-   Decentralized governance
-   Price oracle integration
-   Liquidation mechanism

---

See individual project README for setup and deployment instructions.
